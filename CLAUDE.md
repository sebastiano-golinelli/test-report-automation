# Test report automation

Reads tensile-test PDF reports from three fictional labs, normalizes them (units, dates), checks the
values against the material specifications and writes an Excel summary.

## Layout and commands
- `reportbot/`: the package. Rule-based extraction; for free-text reports there is an optional AI step
  (Claude) that **checks that every quoted value appears verbatim** in the PDF, and otherwise sends the
  field to manual review.
- `samples/`: **synthetic** PDFs generated by `samples/generate_samples.py`
- `tests/`: 15 pytest tests; CI in `.github/workflows/tests.yml`
- `.gitattributes` makes git treat PDFs as binary
- Run: activate `.venv`, then `python -m reportbot samples/pdfs -o output/test_summary.xlsx`
  (`--ai` needs the `ANTHROPIC_API_KEY` environment variable)
- Tests: `pytest`

## Rules
- The AI step is tested with a mocked client only; tests must never need a real API key.
- Never put API keys or tokens in the repository.
- Samples stay synthetic: no real customer data.
- Keep the CI green.
